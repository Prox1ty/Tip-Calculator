# Tip Calculator

A sleek, minimal, and responsive Tip Calculator built with React, Vite, and styled using Tailwind CSS v4 and Shadcn UI components.



## Features

- **Asynchronous Live Calculation:** Computes tip amounts, total bills, and split distributions per person upon form submission.
- **Dynamic Conditional Rendering:** The result summary panel renders smoothly only when a valid calculation is requested.
- **Fluid Layout Architecture:** Fully responsive layout centered via Flexbox constraints against a customized slate charcoal palette.

## Tech Stack

- **Framework:** React 19 
- **Build Tool:** Vite
- **Styling:** Tailwind CSS v4
- **UI Components:** Shadcn UI (Card, Input, Button)
