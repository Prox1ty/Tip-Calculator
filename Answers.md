1. NodeJS is required. run npm install and then npm run dev to start the app locally
> Clone GitHub repository
git clone https://github.com/Prox1ty/Tip-Calculator.git

> Step into the specific project directory folder
cd Tip-Calculator

> Manually download all matching packages from package.json
npm install

> Spin up the local Vite deployment engine
npm run dev

2. I used Vite for the bundler and React with TailwindCSS because I've used React before. I knew of TailwindCSS (have watched tutorials use it) but had never used it myself, so I thought this could be a good opportunity to familizarize myself with it. I used ShadCN because of it's wide use in dark modes in popular apps and thats also the reason why my webpage is mostly dark and gray lol. To make the webpage responsive I used flexbox because i'm familiar with it the most. I had initially used grids in some places but switched to flexbox for those too due to responsiveness issues. 

3. I kept responsiveness in mind for the most part, thats why the frequent use of flexboxes throughout the code. Although due to my lack of experience there could be faults and bugs which I could not come across. I used a form for input resolution to leverage the submit override functionality, thats how I overcame the issue I was facing regarding calculating the bill when user presses enter.
I'm not the best UI designer but I tried to keep the UI readable. I used large fonts for main headers and small text and gray text color (zinc-800 to be exact!) for less important information. For parts that I knowingly skipped, there's probably a lot since I was running out of time. I couldn't work on the assessment project sooner due to exams at university. But yeah the thing I skipped is probably better design. The app was intended to be minimalistic but I'm sure I could've made it better by making the background more intriguing, adding a blur effect in the card background etc.
